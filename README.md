# Blog preview card

A single blog preview card on a yellow page. It shows an article illustration, a Learning label, the publish date, the title, a short summary, and the author.

Open `index.html` in a browser. Bootstrap and the Figtree font load from a CDN, so the page needs a network connection for those styles.

## Screenshots

**The card.** The illustration, article details, and author sit on a white card with a hard shadow.

![Blog preview card for HTML and CSS foundations by Greg Hooper](docs/screenshots/card.png)

**Learning label.** Hovering or focusing the Learning button turns it black with yellow text.

![The same card with the Learning button in its hover state](docs/screenshots/learning-hover.png)

## What's on the page

- Article image from `assets/images/illustration-article.svg`
- **Learning** label
- Published 21 Dec 2023
- Title: HTML & CSS foundations
- A one-sentence summary
- Greg Hooper, with `assets/images/image-avatar.webp`
- A footer that credits Frontend Mentor and Mamadou Moussa Balde

## Built with

- HTML
- Bootstrap 5 for layout and spacing
- Custom CSS in `styles.css` for the yellow page, card size, shadow, and the Learning button
- [Figtree](https://fonts.google.com/specimen/Figtree) at weights 500 and 800

This is a solution to the [Blog preview card challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS).
